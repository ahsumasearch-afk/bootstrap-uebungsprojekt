Medien & Icons

Alle Dateien, die du für das Übungsprojekt einbinden musst – mit Pfad und fertigem Code zum Kopieren.

Pfade: Die HTML-Dateien liegen neben den Ordnern img/ und icons/, deshalb src="img/datei.svg" ohne führenden Schrägstrich. Im CSS dagegen url("../img/datei.svg"), weil das Stylesheet eine Ebene tiefer liegt.

Einbinden

Bild in einer Spalte

<img src="img/lage.svg"
     class="img-fluid rounded-4 shadow-sm"
     alt="Karte mit der Lage des Hostels">

img-fluid nicht vergessen – sonst sprengt ein 1600 px breites Bild das Layout.

Icon neben Text

<div class="d-flex gap-3">
  <img src="icons/standort.svg" alt=""
       width="24" height="24"
       class="flex-shrink-0 mt-1">
  <div>…</div>
</div>

Deko-Icons bekommen alt="" – leer, aber vorhanden.

Hero-Hintergrund (im CSS)

.hero {
  background-image:
    linear-gradient(rgba(12,28,44,.55), rgba(12,28,44,.75)),
    url("../img/hero.svg");
  background-size: cover;
  background-position: center;
  min-height: 78vh;
}

Der Verlauf liegt über dem Bild und macht weiße Schrift lesbar.
